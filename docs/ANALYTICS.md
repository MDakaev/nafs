# Аналитика Nafs

Для РФ/СНГ используем **Яндекс.Метрику**.

## Как подключить (2 минуты)

1. Зайди на https://metrika.yandex.ru/
2. Добавь счётчик для сайта: `https://mdakaev.github.io/nafs/`
3. Скопируй номер счётчика
4. Впиши его в `js/config.js`:

```js
metrikaId: "12345678",
```

5. Запушь / задеплой

Пока `metrikaId` пустой — аналитика просто молчит и ничего не ломает.

## Что уже считаем

- просмотр страницы
- открытие как PWA / с домашнего экрана (`standalone`)
- клик установки
- успешный `appinstalled` (в основном Android)
- отметка Я / Нафс
- клик доната CloudTips
- смена языка
- смена темы
- сброс отметок по периоду

## Рекомендуемые цели в Метрике

Создай цели типа «JavaScript-событие»:

- `install_click`
- `app_installed`
- `mark_me`
- `mark_nafs`
- `donate_click`
- `language_change`
- `theme_change`
- `reset_marks`
