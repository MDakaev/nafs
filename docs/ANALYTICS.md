# Аналитика Nafs

Для РФ/СНГ используем **Яндекс.Метрику**.

## Как подключить (2 минуты)

Счётчик уже подключён: **`111273371`** в `js/config.js`.

Сайт в Метрике: `https://mdakaev.github.io/nafs/`

Если нужно сменить счётчик — впиши новый ID в `js/config.js` и задеплой.
Пока `metrikaId` пустой — аналитика молчит и ничего не ломает.

## Что уже считаем

- просмотр страницы
- открытие как PWA / с домашнего экрана (`standalone`)
- клик установки
- успешный `appinstalled` (в основном Android)
- отметка Я / Нафс
- клик доната CloudTips
- смена языка
- смена темы
- сброс отметок по периоду

## Рекомендуемые цели в Метрике

Создай цели типа «JavaScript-событие»:

- `install_click`
- `app_installed`
- `mark_me`
- `mark_nafs`
- `donate_click`
- `language_change`
- `theme_change`
- `reset_marks`
