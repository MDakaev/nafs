# Способы пожертвований для Nafs

Цель: удобно пользователю, просто тебе, без App Store.

## Короткий вывод

Для твоего случая лучший старт такой:

1. **СБП / перевод на карту** — основной способ для РФ
2. **CloudTips или СберЧаевые** — если хочешь красивую готовую страницу
3. **Boosty** — если хочешь регулярную поддержку и публичную страницу
4. **Ko-fi** — только если появится международная аудитория и способ принимать Stripe/PayPal

Сейчас в приложении уже есть экран с этими кнопками.  
Ссылки вставляются в `js/config.js`.

## Сравнение

| Способ                 | Удобство для пользователя | Сложность для тебя | Комиссия / нюанс                    | Рекомендация               |
| ---------------------- | ------------------------- | ------------------ | ----------------------------------- | -------------------------- |
| СБП / перевод          | Очень высокое в РФ        | Низкая             | Обычно низкая/банковская            | **Лучший MVP**             |
| CloudTips / СберЧаевые | Высокое                   | Низкая             | ~5% на вывод                        | Отличный быстрый вариант   |
| Boosty                 | Высокое                   | Низкая             | ~10% + вывод                        | Если хочешь подписки       |
| ЮKassa / эквайринг     | Высокое                   | Средняя/высокая    | Нужен ИП/ООО, чеки                  | Позже, не для старта       |
| Ko-fi                  | Высокое internationally   | Низкая             | 0% platform на tips + Stripe/PayPal | Если есть зарубежный приём |
| Stripe Payment Links   | Высокое internationally   | Средняя            | Нужен доступ к Stripe               | Обычно сложно из РФ        |

## Что выбрать именно тебе

### 1. СБП — основной путь

Почему:

- пользователи из РФ платят привычно;
- не нужно собирать сложный checkout;
- можно начать с QR или payment link.

Как сделать:

1. Создай ссылку/QR в Т-Банке / своём банке / ЮMoney.
2. Вставь URL в `js/config.js` → `donations.sbp`.
3. В приложении кнопка сразу начнёт открывать оплату.

### 2. CloudTips / СберЧаевые — если хочешь “красиво и быстро”

Почему:

- готовая страница;
- пользователь понимает, что это чаевые/поддержка;
- минимум разработки.

Минус: комиссия выше, чем у простого перевода.

### 3. Boosty — если хочешь регулярность

Бери, если хочешь:

- месячную поддержку;
- публичный профиль;
- возможность позже давать “бонусы” подписчикам.

Не бери как первый и единственный способ, если тебе нужен разовый донат без лишнего шума.

### 4. Ko-fi / Stripe — только под международку

Имеет смысл, когда:

- часть аудитории за пределами РФ;
- у тебя есть рабочий способ принимать Stripe или PayPal.

Для чисто российской аудитории это не лучший первый шаг.

## Что не надо делать сейчас

- Не подключай полноценный эквайринг ради 3 кнопок.
- Не делай in-app purchase логику как в App Store: у тебя PWA, это лишняя бюрократия.
- Не обещай “донат за фичи”, пока нет оферты и понятного статуса денег.

## Практичный план на 15 минут

1. Сделай СБП-ссылку или QR.
2. Опционально создай CloudTips.
3. Впиши URL в `js/config.js`.
4. Проверь кнопки в меню → Пожертвовать.

Пока ссылки пустые, приложение честно пишет, что способ ещё не подключён.
